# Bundled flag fallbacks

These SVGs are shipped with the app so a flag still works when Wikimedia is unavailable. Their URL mapping is in `src/data/flagLocalFallbacks.json`; the matching Wikimedia Commons file URLs and image sources remain in `src/data/flags.json`.

Most files were sourced from `region-flags` version 1.1.0, whose `COPYING` notice says its flags were checked as public domain or exempt from copyright. The remaining regional flags were sourced from the corresponding Wikimedia Commons files. Commons licensing and author information are available on each linked file page; retain those notices if redistributing the artwork separately.
